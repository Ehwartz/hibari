雲雀 Hibari — AI 麻雀训练场  {version}
================================================

日本麻将（四人立直麻将）训练软件：与三名 Mortal AI 对局，自动保存牌谱，
支持牌谱回放、AI 复盘、何切 / 听牌 / 点数练习与数据统计。

运行
----
先将压缩包完整解压，不要在压缩包内直接运行。首次启动需要十几秒加载 AI。

Windows
  双击 Hibari.exe。关闭程序窗口即退出。

macOS（Apple Silicon）
  1. 将 Hibari.app 拖入“应用程序”文件夹（也可留在原处）。
  2. 本程序未经 Apple 签名，首次运行前请在“终端”中执行一次：
       xattr -dr com.apple.quarantine /Applications/Hibari.app
     （若未移动到“应用程序”，请替换为 Hibari.app 的实际路径。）
  3. 双击 Hibari.app。关闭窗口后按 Cmd+Q 退出。

Linux（x86_64）
  在终端中运行 ./start.sh。关闭程序窗口即退出。

模型权重
--------
AI 需要 Mortal 模型权重 mortal.pth，位于：
  Windows / Linux：mjbot_mortal/mortal.pth
  macOS：Hibari.app/Contents/Resources/app/mjbot_mortal/mortal.pth
如果该文件不存在，请自行放入后重新启动。缺少权重时仍可使用听牌练习与点数计算。

系统要求
--------
- Windows 10 / 11（64 位）、macOS 11 以上（Apple Silicon）或 Linux（x86_64，glibc 2.39 以上，
  如 Ubuntu 24.04、Debian 13、Fedora 40 及更新版本）
- Google Chrome（推荐）、Microsoft Edge 或 Chromium
- 不需要显卡，不需要安装 Python。约 1.5 GB 磁盘空间

数据
----
牌谱、设置、头像、练习记录保存在：
  Windows / Linux：本文件夹的 data 目录
  macOS：~/Library/Application Support/Hibari/data
备份或迁移时复制该目录即可；升级新版本时，Windows / Linux 请将旧版的 data 目录复制到新版文件夹。

遇到问题
--------
启动失败时会显示提示；详细日志位于数据目录中的 launcher.log 和 server.log。
